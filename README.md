# Dashboard de vendas

Site estático em português para visualizar e filtrar os dados de vendas incluídos em `index.html`.

## Visualizar localmente

Abra `index.html` em um navegador. O site não exige instalação de dependências nem servidor.

## Publicar no GitHub Pages

1. Crie um repositório GitHub para este projeto.
2. Envie os arquivos `index.html` e `README.md` para a raiz do repositório.
3. No GitHub, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois salve.
6. Aguarde a publicação. O GitHub exibirá o endereço do site na seção **Pages**.

> Antes de usar um repositório público, confirme que os dados incorporados no HTML podem ser divulgados. Para dados internos, prefira um repositório privado.
